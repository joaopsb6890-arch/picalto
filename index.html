Armazenamento de imagens

O Firebase Storage requer o plano Blaze (cartão de crédito). Para evitar cartão, usamos Cloudinary (grátis, sem cartão).

  1. Cria conta gratuita em cloudinary.com (sem cartão)
  2. Dashboard → copia o Cloud Name
  3. Settings → Upload → Add upload preset → Unsigned → copia o nome do preset
  4. Cria o ficheiro public/config.js com esses dois valores (ver public/config.example.js)
